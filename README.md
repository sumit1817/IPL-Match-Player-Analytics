# IPL Match & Player Data Analytics

This project is about exploring IPL match and player data to understand team and player performance across different seasons.

I used SQL, Python, Excel and Power BI to clean, analyze and visualize the data and find useful patterns from the matches.

## About the Dataset

The project contains multiple IPL datasets:

- `ball_by_ball_data.csv` - Ball-by-ball match data
- `ipl_matches_data.csv` - Match details
- `players-data-updated.csv` - Player details
- `teams_data.csv` - Team details

The main ball-by-ball dataset contains around 278,000 records covering IPL seasons from 2008 to 2025.

## Tools Used

- Python
- Pandas
- SQL / MySQL
- Power BI
- Microsoft Excel

## What I Analyzed

### Player Performance
- Top run scorers
- Player performance across seasons
- Batting and bowling performance
- Runs and wickets

### Team Performance
- Team-wise performance
- Season-wise performance
- Runs scored and wickets taken
- Batting and bowling comparison

### Match Data
- Innings-wise analysis
- Runs and wickets
- Extras
- Wide balls and no-balls
- Different types of dismissals

## Power BI Dashboard

I am using Power BI to create an interactive dashboard for exploring player and team performance.

The dashboard will include filters for seasons, teams, players and other performance metrics.

## Project Goal

The main goal of this project is to practice working with a large real-world dataset and use different data analysis tools to turn raw data into useful insights.
